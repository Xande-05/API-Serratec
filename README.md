## Descrição

Este projeto é uma API RESTful desenvolvida como atividade do curso da Serratec.  
Ela tem como objetivo fornecer endpoints para manipulação de dados de forma estruturada, seguindo boas práticas de desenvolvimento em Java com Spring Boot.

---

## Funcionalidades

- Criação, leitura, atualização e exclusão de recursos (CRUD)
- Endpoints RESTful
- Tratamento de erros básico
- Estrutura organizada por camadas (Controller, Service, Repository)

---

## Tecnologias

- Java 17+  
- Spring Boot  
- Maven/Gradle  
- Banco de dados Postgre  
- Postman (para testes de API)
